\section{Experiments}
\label{sec:experiments}

\subsection{Data}

Real CSI 300 data from Baostock API: 94 stocks, 2020-2024, 1,212 trading days. Adjusted prices (splits, dividends handled), no missing values.

Survivorship bias: we excluded delisted stocks. This probably overestimates returns by 1-2\% annually. See Discussion for details.

Processing: winsorize at 1st/99th percentiles, standardize to z-scores cross-sectionally.

\subsection{IC Calculation}

For each day: compute factor values for all stocks, compute 20-day forward returns, calculate Spearman rank correlation. Result: IC time series for each factor.

\subsection{Weighting}

\begin{equation}
w_f = \frac{\max(0, ICIR_f)}{\sum_{f'} \max(0, ICIR_{f'})}
\end{equation}

where $ICIR_f = \bar{IC}_f / \sigma_{IC,f}$ over 60-day lookback. Negative IC factors get zero weight.

\subsection{Portfolio}

Composite score: $S_i = \sum_f w_f \times F_{i,f}$. Rank stocks, select top 20, equal-weight within portfolio.

\subsection{Risk Control}

Maximum drawdown: reduce 50\% if drawdown exceeds 25\%. Volatility targeting: scale to 15\% annual volatility. Stop loss: liquidate 50\% if single-day loss exceeds 5\%.

\subsection{Walk-Forward}

Training window: 60 days for IC estimation. Rebalancing: every 20 days. All returns are out-of-sample. No look-ahead bias.

\subsection{Regime Definition}

Bull: CSI 300 60-day return $> +15\%$. Bear: 60-day return $< -15\%$. Oscillation: between $-15\%$ and $+15\%$.

\subsection{Statistics}

Newey-West HAC:

\begin{equation}
\text{Var}_{NW}(\bar{r}) = \gamma_0 + 2 \sum_{j=1}^{L} w_j \gamma_j
\end{equation}

Bartlett kernel weights, Schwert automatic lag $L = \lfloor 4(T/100)^{2/9} \rfloor$.

\subsection{Baselines}

Equal-weighted factors, static IC weights (full-sample IC, no updating), CSI 300 buy-and-hold.
