\subsection{IC Calculation}

For each trading day $t$:

\begin{enumerate}
    \item Compute factor values for all stocks
    \item Compute 20-day forward returns: $r_{t+20} = P_{t+20}/P_t - 1$
    \item Calculate Spearman rank correlation between factor and forward returns
    \item Result: IC time series $\{IC_t\}$ for each factor
\end{enumerate}

\subsection{IC-Based Weighting}

Factor weights computed from rolling IC statistics:

\begin{equation}
w_f = \frac{\max(0, ICIR_f)}{\sum_{f'} \max(0, ICIR_{f'})}
\end{equation}

where $ICIR_f = \bar{IC}_f / \sigma_{IC,f}$ over lookback window (60 days).

\textbf{Constraints}:
\begin{itemize}
    \item Minimum weight: 0 (exclude negative IC factors)
    \item Maximum weight: 0.25 (prevent over-concentration)
    \item Rebalancing: Monthly (every 20 trading days)
\end{itemize}

\subsection{Portfolio Construction}

\begin{enumerate}
    \item Compute composite score: $S_i = \sum_f w_f \times F_{i,f}$
    \item Rank stocks by composite score
    \item Select top 20 stocks (long-only)
    \item Equal-weight within portfolio
\end{enumerate}

\subsection{Risk Control}

\textbf{Three-layer protection}:

\begin{enumerate}
    \item \textbf{Maximum Drawdown Limit}: Reduce position 50\% if drawdown > 25\%
    \item \textbf{Volatility Target}: Scale positions to target 15\% annual volatility
    \item \textbf{Stop Loss}: Liquidate 50\% if single-day loss > 5\%
\end{enumerate}

\begin{enumerate}

    \item \textbf{Rebalancing}: Every 20 days
    \item \textbf{Out-of-Sample}: All returns are forward-looking
    \item \textbf{No Look-Ahead}: Factor weights determined before holding period
\end{enumerate}

\subsection{Market Regime Definition}

We quantitatively define market regimes using CSI 300 index returns:

\textbf{Regime Classification Rules}:
\begin{itemize}
    \item \textbf{Bull Market}: CSI 300 60-day cumulative return $> +15\%$
    \item \textbf{Bear Market}: CSI 300 60-day cumulative return $< -15\%$
    \item \textbf{Oscillation}: 60-day return between $-15\%$ and $+15\%$
\end{itemize}

\textbf{Threshold Justification}: The $\pm 15\%$ thresholds correspond to approximately 1.5 standard deviations of 60-day returns in CSI 300 historical data, capturing significant market moves while filtering noise.

\subsection{Statistical Testing}

We implement Newey-West HAC standard errors:

\begin{equation}
\text{Var}_{NW}(\bar{r}) = \gamma_0 + 2 \sum_{j=1}^{L} w_j \gamma_j
\end{equation}

where:
\begin{itemize}
    \item $\gamma_j$ = autocovariance at lag $j$
    \item $w_j = 1 - j/(L+1)$ = Bartlett kernel weight
    \item $L = \lfloor 4(T/100)^{2/9} \rfloor$ = Schwert automatic lag
\end{itemize}

\textbf{Implementation}:
\begin{enumerate}
    \item Compute monthly return series $\{r_1, ..., r_N\}$
    \item Calculate mean return $\bar{r}$
    \item Compute residuals $e_t = r_t - \bar{r}$
    \item Calculate Newey-West variance
    \item t-statistic = $\bar{r} / SE_{NW}$
    \item p-value from t-distribution with N-1 degrees of freedom
\end{enumerate}
